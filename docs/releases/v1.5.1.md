# v1.5.1 · 矿物自然错落分散

金块、钻石和特殊物不再围着矿工按固定角度、相近距离排成扇形。新地图将主要目标随机放到九个空间分区，补充物覆盖不同深度；普通、五类事件和备用地图一起调整。目标类型与分区随机配对，不固定整齐行列。

路障随目标定位，间距、边界及最早碰撞继续使用真实轮廓。保留 v1.5.0 的目标大小、物体数量、价值、计时、回速、13 项现行成就、事件概率与商店价格；地图仍验证 45 秒内无炸药／增益达标，原后期路线预算不降低。

## 运行与兼容

下载 Gold-survival-v1.5.1.zip，完整解压后用 Chrome／Edge 打开 index.html，离线可玩，无运行依赖。新开无限、Seed 和每日挑战使用规则 **1.5.1**；相同数字 Seed 的新旧最佳记录分开。已开始的 **1.4.0／1.5.0** 挑战保留当前地图、商店、后续生成和原报价，继续旧挑战仍可能看到原扇形。旧 Seed 终局“重新挑战”使用新规则。

档案主键和结构保持。合法 v1.5.0 档案首次升级前保留原文备份，生涯、图鉴、历史徽章／称号、报告和个人最佳保留。存档仍属于当前浏览器与地址，换文件目录或浏览器可能使用不同存档；本轮没有访问个人档案。
