# v1.5.3 · 扩大抓钩接触范围

钩尖采用半径 **8 个逻辑像素**的连续接触范围，擦边更容易抓到。圆形物体半径加八，矩形按圆角外扩八；石头、火药桶与可回收物统一按最早接触判定，四角不会出现额外方形吸附。像素钩形、摆动角度、绳长、出钩与回收速度保持。

沿用自然错落分散和每关新增八物，普通首关 23 个、后期 32～34 个、事件最多 36 个。目标、单物价值、尺寸、计时、13 项成就、概率和商店价格保持。

## 运行与兼容

完整解压 Gold-survival-v1.5.3.zip，用 Chrome／Edge 打开 index.html，文件直开、离线可玩，无运行依赖。新无限／Seed／每日规则 **1.5.3**；旧 **1.4.0／1.5.0／1.5.1／1.5.2** 挑战保持原抓取判定、地图、数量、后续关与已支付报价，开始新挑战才能体验扩大范围。同 Seed／每日日期按实际规则分别记录。

存档主键和结构保持，v152 首次升级先备份原文，生涯、成就／称号、图鉴、报告及最佳保留。备份失败不覆盖权威旧档。个人存档仍属于浏览器与地址，本轮使用隔离档案。
