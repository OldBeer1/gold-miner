## 游戏阶段结果（整理前）

Git 基线与测量入口保存在 `e0dd756`。四项最小修改已实现。60 帧受控绘制中 fillRect 从 15980 降为 4640，减少约 71%，每帧一次静态背景 drawImage；三个视口的最终 Canvas PNG 哈希完全相同，正式时间和帧数相同。

40054 条逐项碰撞对照、100 张精确地图与五轮交替 Node 测量通过：生成中位耗时旧版 4.07～5.18 ms、新版 1.69～1.95 ms。三视口首关／1000 关共 12 次四秒真实帧间隔测量，中位数均约 6.1 ms；旧版 P95 6.2～6.3 ms、新版 6.2～6.4 ms，新版无 >50 ms 帧或长任务，旧版一次 54.5 ms。不能据此宣称普遍 FPS 提升；可靠改善是减少重绘和生成计算开销。

正式 1700 普通地图、660 普通／事件、60 强制备用、五套发布规则 450 地图／商店及 1500 后期四策略精确对照通过。快照、成长、挑战、存档保护、三视口 UI、声音和真实标签暂停通过。原始随机 Seed 2002876409 连续四关／四店及第五关自然失败：达标 10.53／10.66／19.61／15.49 秒，有效成绩 7250，40 次出钩和回收，自然解锁 9 项成就，四类新增物均实际回收。规则模拟、受控场景和原始计时试玩分别记录，未访问个人档案。
