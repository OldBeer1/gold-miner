## 3. 实现范围

1. 定稿事件机会、前三关保护、不连续出现与单事件限制；概率和参数集中配置，不把建议数值当作已平衡结果。
2. 实现黄金热潮、钻石矿脉、地质不稳定、黑市、贫瘠矿层候选，逐项决定首发可用范围。黑市优先使用已有商品与明确价格修正，新强化商品另立完整规则。
3. 事件按种子、关号与独立用途派生，输出稳定事件 ID 与解析参数，不能因资料页或提示改变随机序列。
4. 在事件修改后的地图上使用真实规则验证 45 秒内无炸药／增益达标路线；维持边界、非重叠、可达、危险物限制与同档压力。
5. 保留有界候选和当前档位备用方案；不可行事件有明确、可复现的降级结果，最终说明与布局一致。
6. 检查事件收益、目标与商品经济组合，不仅比较矿区总价值；少量事件稳定后再考虑新物体与道具。

## 4. 验证与完成条件

覆盖无事件、每个保留事件、相同种子复现、首三关与机会边界、不连续、不叠加、强制候选失败和备用结果；至少包含 19→20、29→30、39→40 升档组合。记录种子、事件参数、路线、时长和预算，有限策略不宣称全局最优。运行受影响规则检查与改动文件语法检查。
