# 第 06 步：像素画面、动画与声音

前置：[第 05 步](05-pause-and-save.md)完成。执行约定见 [分步计划](../IMPLEMENTATION_PLAN.md)。规则来源：[原规格](../GAME_SPEC.md)第 3、4、8、9、10 节。

## 本步结果

已有完整玩法形成统一的复古像素风游戏，各操作具备清楚的视觉和声音反馈，所有页面可直接使用。

## 实现范围

1. 用 Canvas 绘制矿区背景、矿工、钩子、绳索和矿物，统一像素尺度与有限色板；金块、石头、钻石轮廓和颜色清晰可辨。
2. 接入矿工待机和拉拽动作；绳索持续连接矿工与钩尖，物体跟随钩子，视觉轮廓与碰撞体吻合。
3. 收获增加短促金币粒子和金额浮字，炸药增加简短爆炸反馈；效果保持瞄准可见，并遵守暂停和清理规则。
4. 完成开始、商店、暂停、成功、失败和通关页面的中文文案与按钮状态；HUD 明确显示药水效果和炸药可用状态。
5. 最后 10 秒显示醒目时间提醒，达标后显示“已达标，可继续采矿”；菜单、按钮和文字在常见视口下清晰可见。
6. 用 Web Audio 合成出钩、抓取、收获、爆炸、按钮、成功和失败的短音效，首次用户点击或按键后初始化。
7. 全部声音遵守音效开关；暂停时停止持续声音。音频不可用时正常运行游戏；声音与画面运行不依赖远程素材。
8. 在 1280×720 和 1920×1080 验证画布和操作区，短屏幕可合理滚动，缩放后矿区点击准确。

## 本步边界

本步保留前面已验证的玩法规则。若画面调整改变矿物尺寸或位置，同时检查碰撞与布局；最终平衡与完整验收由第 07 步完成。

## 验收

| 检查 | 完成条件 |
| --- | --- |
| 风格与识别 | 全场景风格一致，三类矿物易分辨，按钮和数值易读 |
| 运动关系 | 绳索连接正确，拖拽物体跟随正确，动作与钩子状态一致 |
| 反馈与暂停 | 收获和爆炸可辨识、不过度遮挡，暂停冻结动画，返回主页清理效果 |
| 状态提示 | 最后 10 秒和达标提示正确，各页面有清楚的下一步 |
| 声音 | 首次交互后可播放对应音效，关闭后全部静音，暂停停止持续声音 |
| 视口与缩放 | 两种指定视口完成检查，画布比例及点击坐标正确 |
| 本地资源 | 直接打开页面可显示画面和使用声音，无远程素材依赖 |
