# 第 05 步：暂停、输入与本地保存

前置：[第 04 步](04-shop-and-items.md)完成。执行约定见 [分步计划](../IMPLEMENTATION_PLAN.md)。规则来源：[原规格](../GAME_SPEC.md)第 4、7、8、10 节。

## 本步结果

完整处理暂停与恢复、不同页面的输入边界，以及音效设置和最高记录的本地保存。

## 实现范围

1. Esc 和暂停按钮切换当前关暂停状态；暂停页提供继续与返回开始界面。
2. 暂停冻结计时、钩子、携带物体以及所有受游戏时间驱动的动画。恢复时重置时间基准，避免计时跳变或物体瞬移。
3. 通过 `document.visibilitychange` 在游玩页面隐藏时自动暂停；返回标签页后保持暂停，由玩家主动继续。
4. 汇总输入状态检查：暂停、商店、结算不处理出钩和炸药；菜单按钮不穿透，长按不重复触发，游戏按键不误滚动页面。
5. localStorage 使用项目专属键，仅保存音效开关和最高记录。默认音效开启、记录为 0；读取时校验类型与值，读写异常或损坏数据均不影响游戏。
6. 最高记录仅在成功结算后使用本轮已过关总收入更新；失败尝试不参与。开始页显示记录，文案明确其含义。
7. 刷新只保留以上两项，回到开始界面；新一轮从第 1 关的初始钱包和道具开始。
8. 复核返回主页、重新开始、连续重试和页面切换的循环清理，为保存异常与最高记录规则增加轻量自动检查。

## 本步边界

本步完成音效开关的状态与持久化，实际声音在第 06 步接入。第 06 步新增的动画与持续声音也必须遵守本步的暂停入口。

## 验收

| 检查 | 完成条件 |
| --- | --- |
| 手动暂停 | 暂停前后时间与物体位置一致，暂停时无法出钩或炸药 |
| 自动暂停 | 切到其他标签页后冻结，返回后仍暂停，继续后平稳恢复 |
| 输入边界 | 菜单、商店、结算只响应各自操作，按钮不穿透，按键无意外滚动 |
| 刷新行为 | 音效与最高记录保留，关卡、钱包、库存和购买状态重新初始化 |
| 存储异常 | 模拟 localStorage 不可用或无效内容后仍可启动和游玩 |
| 记录规则 | 过关更新记录，失败不提高记录，购物支出不减少成功累计收入 |
| 循环管理 | 连续暂停、返回、开始、重试后没有重复更新或重复结算 |
